# LanguageRecap brand v2 - notebook direction

Recolored to match the app's paper/journal aesthetic (direction A from the
comparison). Same concept as before (speech bubble = the lesson, dots with
growing gaps = expanding review intervals, amber/terracotta dot = next
recall) - only the palette and wordmark typeface changed, so the concept
carries over cleanly.

Colors: paper #F6F0E4, ink (forest green) #173226, cream #FFFDF6,
terracotta #C97B45, hairline border #E7DDC7.
Wordmark: Lora Bold (SIL OFL, same font family as Google Fonts' Lora used
in-app), converted to outlines - no font file needed at runtime.

## Files
- logo-mark.svg / icon-*.png / favicon.ico / apple-icon.png / manifest.webmanifest
  - same purpose and Next.js placement as the v1 set.
- logo-horizontal.svg - ink wordmark, transparent background, for light surfaces.
- logo-horizontal-on-paper.svg - ink wordmark on the paper cream background,
  for headers that sit directly on the app's page background.
- logo-horizontal-light.svg - cream wordmark on ink background, for dark
  surfaces or footers.

Replaces the v1 (indigo/violet) set - swap all references, don't run both.
